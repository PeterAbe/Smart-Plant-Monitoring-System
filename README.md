# Smart-Plant-Monitoring-System

# SEP 769 – Smart Plant Care & Monitoring System
## 4-Week Project Gantt Chart

**Project Duration:** 4 Weeks  
**Team Members:** Tommy Phang, Leo Huang, Paul Li, Osayonamen

---

## Week 1 – Planning and Dashboard Development

**Goal:** Complete the dashboard design and set up GitHub.

| Day | Task | Description |
|---|---|---|
| Day 1 | Hardware Research | Research hardware components, wiring requirements, and system architecture. |
| Day 2 | GitHub Setup | Clone the course repository, create the project folder, and organize the code structure. |
| Day 3 | Dashboard Development | Complete the visual design of the Flask web dashboard using HTML and CSS. |

## Week 2 – Hardware Implementation and Testing

**Goal:** Assemble hardware and implement the core system functionality.

| Day | Task | Description |
|---|---|---|
| Day 1 | Hardware Setup and Testing | Connect the Raspberry Pi, moisture sensor, relay, water pump, and LED. |
| Day 2 | Sensor Code Implementation | Develop Python code to read and calibrate soil moisture values. |
| Day 3 | Watering Logic and LED | Implement automatic watering logic, relay control, and LED status indicators. |
| Throughout Week 2 | PowerPoint Preparation | Prepare the project presentation, including architecture, hardware, software, and system design. |

## Week 3 – Database Integration and System Testing

**Goal:** Integrate all components and ensure the prototype works correctly.

| Day | Task | Description |
|---|---|---|
| Day 1 | Logs and Database | Implement SQLite to store moisture readings and watering history. |
| Day 2 | Troubleshooting and Integration | Integrate Flask, SQLite, sensors, and watering functionality. Identify and fix issues. |
| Day 3 | System Testing | Test automatic watering, sensor readings, dashboard updates, and data logging. |

## Week 4 – Video Demonstration and Final Submission

**Goal:** Complete the demonstration video and prepare all submission materials.

| Day | Task | Description |
|---|---|---|
| Day 1 | Video Preparation | Prepare the demonstration script, assign speaking roles, and verify the prototype. |
| Day 2 | Video Recording and Editing | Record hardware assembly, code explanation, and complete system demonstration. |
| Day 3 | Final Review and Submission | Review the PowerPoint, video, and GitHub repository. Submit all required files. |
